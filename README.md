# David Machado Pérez: personal academic website

A static site served by GitHub Pages. There is no build step: edit `index.html` and commit.

- `index.html`: the whole site
- `David_Machado_Perez_CV.pdf`: the CV linked from the sidebar
- `photo.jpg`: your portrait (optional). Add a square image with this exact name. Until then the site shows your initials.
